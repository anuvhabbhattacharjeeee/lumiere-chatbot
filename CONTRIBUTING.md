# Contributing

Contributions are welcome. For substantial changes, open an issue first to agree on the approach.

1. Fork the repository and create a focused branch.
2. Install the project and development dependencies with `pip install -e ".[dev]"`.
3. Make the smallest change that addresses the issue and add or update tests.
4. Run `pytest` and check Python syntax before opening a pull request.
5. Describe the user-visible changes and any configuration impact in the pull request.

Do not commit `.env` files, API keys, or other credentials. Follow the project Code of Conduct.
